# Contribuindo

O projeto aceita relatos que possam ser verificados, principalmente sobre documentação, terminologia, compatibilidade e comportamento da tradução quando uma build pública existir.

## Antes de abrir uma Issue

- confirme que o assunto pertence exclusivamente a este projeto;
- procure uma Issue existente;
- não envie arquivos proprietários do jogo;
- remova e-mails, IDs de conta, tokens e outros dados pessoais;
- informe plataforma, versão do cliente e versão do mod quando aplicável;
- descreva passos objetivos para reproduzir o problema.

## Pull requests

Pull requests são revisados pelo mantenedor e não alteram o projeto automaticamente. Mudanças devem ser pequenas, rastreáveis e limitadas a um objetivo. Não inclua executáveis sem origem, conteúdo extraído do cliente, credenciais ou dependências binárias desnecessárias.

## Sugestões de tradução

Quando o catálogo estiver disponível, uma sugestão deverá informar a tela ou contexto, o texto exibido, a proposta e o motivo da mudança. A tradução integral e a revisão manual são acompanhadas separadamente; uma correção aprovada será marcada com o estágio editorial correspondente.

## Código de conduta prático

Mantenha as discussões técnicas, respeitosas e relacionadas ao mod. Assédio, spam, exploração de falhas para prejudicar usuários e distribuição de arquivos proprietários não serão aceitos.
